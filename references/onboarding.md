# 首次路径确认与全局记忆

此步骤先于任务调查、下载、创建运行目录和派发代理。本次仅维护 skill 源码不等于执行一次 arena 任务，不因此要求用户提供路径。

## 读取优先

- 确认当前客户端身份。读取客户端已有的全局记忆文件/服务；若没有另行配置，使用用户拥有的 `$CODEX_HOME/AGENTS.md`（CODEX_HOME 未设置时为 `~/.codex/AGENTS.md`）作为可读的全局偏好文件，不编辑内部记忆数据库。
- 检查是否存在明确标注为“Codex 保存临时文件的路径”的固定路径。既有自然语言记忆也有效，不能仅因为没有本 skill 的标记块就重复询问。多电脑按客户端区分，不把远程服务器的全局文件当成用户电脑的记忆。
- 找到有效记录则直接复用，不询问路径或是否固定。路径不可访问时先检查当前是否远程和映射情况，不静默改目录；必要时说明具体问题请求修正。
- 远程无法读取客户端记忆时，先尝试现有本地工具或可信会话提供的记忆；不能声称记忆不存在。若仍无法取得，在执行前说明并询问本次路径/是否保存。

## 首次交互

未找到固定记忆且本次请求未提供时，使用原生提问工具同时询问：

1. “请指定 Codex 在你电脑上保存临时文件的绝对路径，例如 D:\\CodexFiles。Skill Arena 的本地报告也会保存在这里的任务子目录。”（自由输入）
2. “是否将此目录固定为 Codex 保存临时文件的路径，写入全局记忆，今后直接复用？”选项：“是，固定并记住”“否，仅本次使用”。

收到路径和选择后才执行任务。已在本次请求给出相应答案时不再询问；默认/预选值不算同意。仅本次使用不能写全局记忆，也不能因旧 delivery-preferences.json 存在就推定用户同意全局固定。

## 保存与目录布局

用户选择固定后，追加或更新最小偏好段，保留其他全局指令。辅助命令：

```sh
python scripts/path_memory.py lookup CLIENT_GLOBAL_MEMORY CLIENT_ID
python scripts/path_memory.py remember CLIENT_GLOBAL_MEMORY CLIENT_ID --path ABSOLUTE_LOCAL_ROOT --fixed
```

`--fixed` 只在用户明确同意后使用。全局段标明“Codex 保存临时文件的路径”，按客户端保存；不把路径提交到公共仓库。写入后回读确认，写入失败则说明尚未固定，不能谎称记住；本次路径明确后可执行任务。

本地布局：`ROOT/skill-arena/RUN_ID/report.html` 为报告；`ROOT/skill-arena/RUN_ID/tmp/` 为临时文件，其他持久成果分别存放。不要因根目录叫临时路径而自动删除报告。远程计算的中间文件可在服务器临时目录，传回本地的报告必须进入同一已确认 ROOT。

全局配置是用户偏好记录，由加载它的代理遵守，不宣称本 skill 能强制更改所有 Codex 进程的底层临时目录。
