<h1 align="center">Skill Arena</h1>
<p align="center"><strong>同一个任务，多种 skill 分别尝试，帮你选出更合适的结果。</strong></p>

---

## 它能帮你做什么？

面对几款看起来都不错的 skill，你可能不知道哪一款更适合自己的任务。Skill Arena 会帮你寻找合适的 skill，让它们各自完成一次任务，再比较实际结果，而不是只看介绍或热度。

你只需要说清楚想做什么。**有材料就附上，没有也可以直接开始。**

例如，你想规划一篇英文期刊论文：Skill Arena 会挑选 3–5 款适合的学术 skill，分别生成完整方案，再由一个未参与生成的 Codex 评估这些方案，解释各自的优点、缺点和适用场景。

## 怎么使用？

首次使用会先请你指定本地文件保存目录，并询问是否固定记住。选择固定后写入全局记忆，以后直接复用；也可仅本次使用。

将本项目作为 skill 添加到 Codex 后，直接说：

> 使用 $skill-arena，帮我规划一篇关于强化学习辅助建筑结构设计的英文期刊论文。

也可以用于其他任务：

> 使用 $skill-arena，帮我制作一份介绍研究成果的演示文稿。

还没有添加 skill？把项目下载到本地，让 Codex **“读取这个项目的 SKILL.md，并用它完成我的任务：……”** 即可。

## 它会怎样完成任务？

| 步骤 | 你会得到什么 |
| --- | --- |
| **寻找候选** | 先广泛调查，再选 3–5 个适合的 skill 或工具包 |
| **分别完成** | 每个候选独立完成一份结果，工具包可使用自身模块 |
| **比较评价** | 用同一套任务要求检查结果，给出排名和具体依据 |
| **留下记录** | 保存完整结果、对比报告和 skill 来源，方便以后复用 |

所有方案使用**相同的 Codex 模型**，不要求相同耗时或预算。首次比较还会加入一份普通提示词方案作为参照。

## 候选怎么选？

先调查约 **8–12 个候选**，尽量覆盖不同来源，再结合任务匹配、工作流、运行条件、**GitHub stars** 和维护情况选出 3–5 个。你指定的项目一定会审查，并说明取舍；不足时不凑数。

**除你明确指定的项目外，GitHub stars 少于 10 的 skill 或工具包不纳入候选。** 星数未核实的 GitHub 项目暂不自动入选；候选不足时不会降低门槛。

单个 skill 和完整工具包都能参加。工具包可以使用自身模块，各候选独立运行，内部代理也使用相同模型。**stars 帮助选候选，结果好不好仍看实际产物。**

> 使用 $skill-arena，帮我规划论文，也请考察 academic-research-skills 及其 Codex 版本。

开始前会展示候选及理由；报告中每款 skill 只介绍项目来源、stars、简介和最新更新时间。

## 看完结果，还能接着做吗？

可以。每轮结束后，会在会话中提供**可点选的提示项和输入框**：

| 点选操作 | 接着填写什么 |
| --- | --- |
| **优化已有方案** | 选方案，输入要改进的地方 |
| **重做已有方案** | 选一个、多个或全部方案，可补充新要求 |
| **满意，接着做** | 选方案，输入下一项任务 |
| **都不满意，调整候选** | 可增加 2 款新 skill，并移除指定候选或评分最低的 2 款 |
| **先保留** | 记住选择，暂不执行 |

选项会显示 **skill 名称＋方案特点**，例如 `marketing-design — 四阶段清楚、排名附理由`，不需要记 A、B、C。单项可点选；多项也可在输入框写出名称。若当前客户端不支持交互控件，直接用文字回复即可。

**例：** 选中满意的文献调研方案 → 点“满意，接着做” → 输入“根据这份调研写论文提纲”。

**都不满意时：** 可以选“增加 2 款新 skill”＋“移除评分最低的 2 款”，再输入“更关注建筑结构设计”。也可以只增加或只移除。若低分项并列、无法明确选出两款，会展示名称请你选择。

接续时沿用所选 skill 和各自成果；移除只影响下一轮，旧结果始终保留。

## 结果怎么看？

打开 **report.html**，在一个文件里查看所有方案：

- **顶部选名称**：直接跳到对应 skill 的完整结果。
- **按需展开**：正文、章节和参考资料可单独展开或收起，也可一键全部展开／收起。
- **先读结果，最后看评估**：方案用列表、表格和必要示意图呈现，排名与评分依据放在末尾。

**例：** 点击 `hypothesis-generation` → 阅读完整方案 → 收起已读章节 → 点击“查看评估”。原始文件也可从报告下载。

评分接近时可以并列；证据不足时会说明原因。一次结果更好，不代表这款 skill 在所有任务中都更好。

## 在远程服务器上运行怎么办？

Skill Arena 会先询问是否将最终报告发回本地，保存到上面确认的目录。

- **选择发送且可直接传输**：自动选择预计最快的可用通道，传回报告并在本地校验。
- **不能直接发送**：提供两个选项——“通过反向连接传输”或“自行下载文件，无需 Codex 帮助”。
- **选择不发送或自行下载**：给出远端文件位置和下载说明，不继续自动传输。

反向传输使用临时连接，结束后关闭；其他原始文件仍按需下载。只有本地校验通过才会说“已发送到本地”。

> 使用 $skill-arena 帮我规划论文，临时文件目录用 D:\CodexFiles，并固定记住。

目录偏好按电脑保存，不会把服务器目录当作本地路径。
